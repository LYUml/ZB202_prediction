## 当前参与模拟的假设

| 参数 | 演示值 | 待确认依据 |
| --- | --- | --- |
| 房间有效体积 | 300 m³ | 确认边界、净高及有效空气体积 |
| 房间分配总送风 | 0.5 m³/s | 实测或可靠平衡报告；未按截图总量分配 |
| 室外 CO₂ | 420 ppm | 室外或新风入口测量 |
| 人均 CO₂ 排放 | 0.000005 m³/s/人 | 人员活动与参数辨识 |
| 渗透换气 | 0.2 次/小时 | 门窗/渗透评估 |
| 执行器时间常数 | 120 秒 | 指令与反馈的时序记录 |
| 室外空气比例范围 | 0.02～0.6 | 实际新风测量与风阀特性 |
| 开度曲线指数 | 1.5 | 标定；当前仅为单调演示曲线 |

配置中每个上述参数记录 value、unit、source。情景中的初始 CO₂、初始开度、人数日程和反馈目标同样是假设；比例反馈目标不是法规阈值或推荐设定值。

改变假设会改变控制比较结果。物理检查通过只证明代码符合所写方程，不证明真实 ZB202 参数或控制效果正确。

## 修订充分混合假设的观测解释

仅用原始前70%训练标签检查，五点均实际有观测的6343个五分钟箱内，相对AM103_05的中位差：AM103_06为+135ppm、AM103_07为−3ppm、AM103_08为−135ppm、AM308为−10ppm。AM103_08在12274个训练观测箱低于假定室外420ppm。

这不能证明设备故障或给出绝对校准：测量不是严格同时，真实空间梯度、相对偏移和其他因素仍需核实。但它不足以支持“所有原始读数都直接等于同一充分混合状态”。room.json现明确将模拟状态视为未校准的区间平均潜在状态，直接五点观测映射尚未建立。历史预测仍使用原始各点标签，不平移它们以降低误差，也不将室外假设降到某个点位基线来凑合。

体积V、人数N与流量Q同时成比例变化时，质量守恒中的N/V和Q/V不变。例如V300→600、N20→40、Q0.3→0.6，其他条件相同，模型CO₂轨迹完全一致。因而不能只用CO₂把这三类参数一起“优化”到唯一真实值。对应审查产物：artifacts/research/assumptions-audit-20261020/audit.json。数值参数继续作为明确假设，后续做范围/敏感性，而非伪装成辨识结果。
