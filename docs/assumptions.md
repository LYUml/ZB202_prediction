# 参数与证据

## 截图参考

设备 AHU-LG1-10；服务区域标注 ZB202。截图观测时间未知，不能与 IoT 历史序列直接对齐。

| 点位 | 截图读数 |
| --- | --- |
| 风阀控制 / 实际位置 | 30% / 11% |
| 总送风 | 8,168 L/s |
| 送风 / 回风温度 | 22.3 / 23.4 °C |
| 冷冻水阀控制 / 反馈 | 51% / 48% |
| 风机控制 / 频率反馈 | 60% / 40 Hz |
| 运行 / 模式 | On / Auto |

这些读数存于 `configs/ahu.json` 的 `snapshot_only`，不参与当前模拟。不能据此诊断指令—反馈差异，也不能直接把总送风乘以开度得到新风量。

## 当前参与模拟的假设

| 参数 | 演示值 | 待确认依据 |
| --- | --- | --- |
| 房间有效体积 | 300 m³ | 确认边界、净高及有效空气体积 |
| 房间分配总送风 | 0.5 m³/s | 实测或可靠平衡报告；未按截图总量分配 |
| 室外 CO₂ | 420 ppm | 室外或新风入口测量 |
| 人均 CO₂ 排放 | 0.000005 m³/s/人 | 人员活动与参数辨识 |
| 渗透换气 | 0.2 次/小时 | 门窗/渗透评估 |
| 执行器时间常数 | 120 秒 | 指令与反馈的时序记录 |
| 室外空气比例范围 | 0.02～0.6 | 实际新风测量与风阀特性 |
| 开度曲线指数 | 1.5 | 标定；当前仅为单调演示曲线 |

配置中每个上述参数记录 value、unit、source。情景中的初始 CO₂、初始开度、人数日程和反馈目标同样是假设；比例反馈目标不是法规阈值或推荐设定值。

改变假设会改变控制比较结果。物理检查通过只证明代码符合所写方程，不证明真实 ZB202 参数或控制效果正确。

## 后续优先补齐

1. 空间边界、净高及 AHU 实际服务范围。
2. 新风/回风路径及总送风读数的单位、倍率和房间分配。
3. 阀门指令、位置反馈和实际新风量的同步历史。
4. 传感器位置、偏差、离线及占用事件上报规则。
