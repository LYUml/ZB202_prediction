## 编码契约

默认 `safe-v2`，仅训练时间段拟合参数。二值占用/门磁保持原始0/1；缺失数值填0并携带mask和age。训练完全缺测的特征全部三个通道冻结为0，并保存禁用清单；常数连续变量数值通道冻结，mask/age保留。连续变量仍以训练均值和尺度编码；不按本次旧测试选择裁剪阈值。输出锚点仍是当前真实可用CO₂，不对输出裁零。

旧 `legacy-v1` 仅供既有权重重放，首轮diagnose显式使用它；不能用safe-v2输入评价legacy-v1权重后称之为原模型成绩。训练缺测通道在未来有数据时需以新训练版本吸收，而非在现有模型中悄悄启用。

所有原始标签保留，包括9500ppm；本轮没有根据测试表现筛除标签。接收时间仍未知，因果性只按记录时间成立。

## 固定实验

使用已有、通过SHA-256校验的causal-v1处理数据，避免改变对齐规则与输入编码同时发生。原时间序列长度为N，整数边界取floor(N×fraction)。

| 折 | 训练终点 | 内部验证终点 | 外部开发评估终点 |
| --- | ---: | ---: | ---: |
| rolling-1 | 40% | 45% | 50% |
| rolling-2 | 50% | 55% | 60% |
| rolling-3 | 60% | 65% | 70% |
| exposed-stress | 70% | 85% | 100% |

每个样本的全部未来标签必须留在对应集合；验证和评估允许引用边界前的历史上下文。内部验证仅用于选择神经网络epoch；外部开发评估标签不参与该折梯度与早停。后续折训练可以包含前面已发生的开发评估段，是扩展窗口验证。

前三折均在原训练时间范围内；它们仍然属于用于开发的数据，而且方案受既有全量诊断启发，不能称为全新未见测试。旧测试exposed-stress明确单列，不作为调参依据。

- 全部模型：过去48步、未来12步、五个CO₂点位，当前全部CO₂可用，最低历史覆盖80%，相同未来真实标签和mask。
- 特征：all为完整100通道；co2_only为五点CO₂的数值/mask/age与4个日历通道，共19通道。持续值为共享参照。
- Ridge：同一历史信息压缩为末值、窗口均值和末首差；对每个未来时距/点位独立拟合标准化CO₂变化，带不惩罚截距；alpha=10，仅训练标签进入拟合。
- TCN：沿用32通道、kernel=3、dilation=1/2/4/8与直接残差输出头。
- LSTM：单层32隐藏单元，末隐状态连接12×5直接残差输出头，初始持续值；与TCN同一训练损失和优化器配置。单层LSTM不设层间dropout，与TCN正则化机制不完全相同。
- 神经模型种子42/43/44；固定最多12轮、patience=3，不进行参数搜索。all和co2_only均跑三折；旧测试压力检查仅跑all。

以上为有限预算初筛，不是对各模型做完充分调参后的上限比较。Ridge有历史压缩，表示能力不同；参数量和实际训练秒数一并报告。每折每种特征设置只拟合一次确定性Ridge，神经模型不挑选最佳种子。

## 指标与追溯

报告总体/10、30、60分钟/各点位MAE与RMSE，P99绝对误差、中位误差、全部输出的负预测数量与最低值；另报60分钟真实相对当前变化>20ppm的标签误差（与之前诊断口径保持一致，不用于训练或筛除全量评价）。

种子均值与样本SD描述初始化稳定性；重叠窗口不是独立样本，不将种子SD当泛化置信区间。支持域之外的极端事件应保留为压力测试，不能通过平均MAE掩盖。

运行在训练前保存配置、处理数据和代码哈希；每次拟合后追加结果。权重、预测与标签存artifacts/forecasting/<run>/，阶段汇报仅按需整理到reports/，运行过程不自动生成Markdown报告。需要新增未参与开发的时间数据，才能做下一次独立最终检验。没有BA动作输入，任何预测改进均不证明阀门因果响应正确。

### 物理结构与解释性要求

本轮目标包含防止过拟合和物理可解释性；不以不同方法加权混合来追逐数值指标。参考 [CO₂ 室内质量守恒灰箱研究](https://arxiv.org/abs/2405.00582)，比较单一结构化动态候选：恒定有效条件下 `C(t+h) = Ceq + (C(t)-Ceq) exp(-kh)`。该表达式与充分混合、恒定源项和有效交换率下的质量守恒解形式一致，但当前数据没有同步新风、送风浓度、人数或实际到达时间，Ceq 与 k 是预测用潜变量，不能宣称辨识真实通风或可推导阀门动作的因果影响。五点不一定充分混合；若该结构的适用假设或多折误差表现不支持采用，就保留结果而不将其部署。旧数据的物理形状 relaxation 候选三折 MAE 为 9.417、8.138、9.512 ppm，不能假设它在新数据上有效。

`configs/forecasting/latest-physics.json` 用最近数据的前两个开发折比较该候选，并保留固定种子、内部早停及与现有预测相同的标签。第三开发折可用于后续确认，末尾留出段不得参与选参。按用户要求采用完整单一模型的预测，而非对不同方法加权；已有冻结模型和持续值仅作为对照。物理结构无充分效果时不强行加入。

开发折结束后，`scripts/experiments/paired_development.py` 依据文件哈希和共同标签重算冻结模型、候选及持续值的配对指标。若开发结果支持继续，预先记录候选种类及固定种子 42，`scripts/experiments/latest_holdout.py` 用前 80% 训练、80%–90% 早停、最后 10% 一次性比较；不得按该段挑种子或反复选模型。它同时检查快照完整箱截止时间，保存单一模型权重、逐日/逐点/时距指标与逐窗口预测。该末段已用于冻结模型及误差反馈离线试验，不是全新盲测，未来新到数据仍需再次前瞻确认。新模型如未稳健胜过原冻结模型，应保留原模型。

截至本轮开发试验结束：物理 relaxation 在前两折三个种子的 MAE 分别为 8.595/8.687/8.497 与 9.326/9.331/9.373 ppm，对应冻结模型为 6.817 与 7.585 ppm；因此不采用该物理结构。两折中 5、30、60 分钟均有观测的窗口-传感器对里，约 38.4% / 36.4% 的两段变化方向相反且每段变化至少 5 ppm；这些窗口相互重叠，不能视为独立事件，只说明固定平衡点的单调轨迹存在结构限制。原始观测不剔除。第三折验证段含一个 9500 ppm 观测，会在多个重叠窗口中反复影响早停指标；其来源未确认。

### 最新开发比较与留出结果

依 [PatchTST 论文](https://arxiv.org/abs/2211.14730) 的时间分块和通道共享思想，另实现轻量 `PatchTransformer`：每个点使用其自身 CO₂、mask、age 和共享日历特征，经同一个 patch 编码器预测；它不是原论文实现，也不是多种方法加权。预设两折、三个种子、内部早停；第一折 MAE 6.557/6.740/6.516 ppm，第二折 7.901/7.811/7.787 ppm。后者全部差于冻结模型的 7.585，故不按单一好折更换方法。

预先按开发折选择单个 TCN、固定种子42，并以训练前80%、早停80%–90%、留出最后10%进行一次比较。运行 `artifacts/forecasting/20261102T134205Z-latest-holdout-fd6d707f/`：2323个窗口、124416个真实标签；候选 MAE/RMSE 9.064/15.489 ppm，原冻结模型 9.438/16.611 ppm，持续值 11.646/19.466 ppm。60分钟 MAE 为 11.259/12.014/14.938 ppm；候选 AM103_05 从 8.914 变为 9.054 ppm，其余四点改善。9个香港日期块的描述性 10,000 次 bootstrap 对 MAE 改善区间为 −0.069 至 1.011 ppm，含零且天数少；多数改善集中于10月26日，去除该日仅作敏感性检查后为 8.024 对 8.109 ppm。不能把这些数值当成独立前瞻验证或每一天都更好。

模型和预测的哈希及权重复原核验已记录；`scripts/validation/inspect-latest.py` 可独立核对保存的 MAE/RMSE 与模型/预测文件哈希。候选在最新快照时点的预测由 `scripts/experiments/predict_candidate.py` 生成，人工测试替换全部未来标签后输出不变。候选按已有留出段结果仅供实验使用；原冻结模型仍是默认，后续新增时段应先固定权重和验证协议再独立确认。
