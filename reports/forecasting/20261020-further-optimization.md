# 进一步优化：特征消融、独立点位与组合

2026-10-20。新增17次神经拟合，完成三个预定检查。实际收益较小：固定三种子预测平均的开发MAE为7.435 ppm，上轮三种子单模型MAE均值为7.547 ppm，降低约1.5%。没有删除原始标签或裁剪预测；没有再评价旧测试段。

## 方法与选择规则

沿用原3个扩展窗口、训练段标准化和safe-v2输入规则。仅原始前70%的开发时段传入训练/评价，原验证与测试段排除。所有起点、真实标签和mask与上轮逐折核对。

特征与独立点位先用seed42筛选，只有三折内部验证均值优于CO₂基线才追加43/44；不会按外部开发MAE选配置。所有候选均未通过这个追加条件，因此未执行无收益的确认拟合。筛选只代表当前结构、预算及时间范围，不证明辅助测量永远无用。

## 特征与点位隔离

下表全部为同一种子42、三个开发窗口等权平均，确保筛选比较一致。

| 方案 | 内部验证MAE | 外部开发MAE |
| --- | ---: | ---: |
| 联合TCN，仅CO₂/mask/age/日历 | **8.893** | **7.462** |
| 加温湿度组 | 9.414 | 8.198 |
| 加占用组 | 9.191 | 8.115 |
| 加门磁组 | 9.038 | 8.020 |
| 加功率组 | 9.267 | 8.341 |
| 五个局部独立TCN | 9.296 | 7.678 |

独立TCN仅读取自身CO₂/mask/age与共同日历，五个网络独立参数；每个16通道，合计30,860参数，联合版32通道、26,204参数。共用批次、优化器步进及全局梯度裁剪。这个比较同时改变跨点输入、权重共享与容量，不能单独把结果归因于“点位互相干扰”。本轮没有证据支持拆成独立点位。

## 三种子与Ridge组合

固定平均三个TCN的预测，不挑选最佳种子。三折等权结果：

| 方案 | MAE | RMSE |
| --- | ---: | ---: |
| 原三种子单模型指标均值 | 7.547 | 10.626 |
| 固定三种子预测平均 | **7.435** | **10.479** |
| TCN平均与Ridge各50% | 7.608 | 10.540 |
| 内部验证选择一维凸组合 | 7.483 | 10.491 |

组合权重在每折内部验证段从0/0.25/0.5/0.75/1选择，全部点位和时距共用一个权重。三折选择的TCN权重为1、0.5、1。第二折的验证选择在外部开发段未优于纯TCN平均，说明增加校准自由度不保证泛化。

“平均预测的MAE”与“各模型MAE的平均”不同，前者才是组合实际产生的预测成绩。组合需要运行三个网络并保留三份权重，增加推理与存储成本；收益约1.5%，没有证明统计显著性或新的未见时段泛化。

## 轮数上限检查

原9个CO₂联合TCN拟合中，7个已满足patience=3早停；仅rolling-1 seed42和rolling-3 seed44的最优checkpoint触及12轮上限。将这两次的上限延长为24轮，其余参数不变。

两次从同一种子重训的前12轮内部验证历史与原记录精确一致；两次都在15轮早停，最佳checkpoint仍是12轮。新旧预测逐项完全相同。其余7次按早停等价条件复用，因此上限增加没有带来额外改善；没有通过开发误差决定退回旧权重。

## 结论与下一步

暂保留联合CO₂ TCN作为单模型候选，固定三种子平均作为计算预算允许时的候选输出方式。当前结果不支持继续加入上述辅助组、拆分点位或单纯延长训练。

已有开发窗口已反复使用，下一优先级是冻结候选，在新增时间数据上确认，尤其检查变化段、缺测和尖峰。PIAD-SRNN/DLinear仍未实现；如继续扩展方法，应沿用同一评价协议，而非继续按旧测试调整配置。无BA动作输入，不能据此宣称已识别阀门响应。

25项代码检查通过；新增覆盖特征排他性、点位输入隔离、组合校准掩码和早停复用条件。三个新运行的全部产物/来源代码哈希与63组MAE/RMSE均核对；独立模型和延长预算模型的代表性checkpoint精确重放通过。本轮所有候选输出均无负预测，但不代表任意未来输入都有物理有效性保证。
