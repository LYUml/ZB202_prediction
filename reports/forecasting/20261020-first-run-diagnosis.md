# 首轮 TCN 失控诊断

2026-10-20；冻结运行 `20261018T131219Z-d95c977c`。不训练、不调参、不删除原始记录。测试段已暴露，本报告是事后取证，不能作为重新选模的独立测试结果。

## 结论与证据

**本轮主要失控原因已定位到训练期完全缺测特征的标准化与未训练权重路径；不是单纯网络容量不足。** 另有测试期 CO₂ 极端事件加重尾部误差，真实性待核实。

`VS341_04/last_occupancy_event` 在训练时间段没有任何有限值。旧输入实现因此得到 mean=0、scale=0.001，训练数值通道恒为0，后期事件值1却变成1000。该数值通道所连权重从未得到有效输入的训练信号（权重衰减仍可能改变权重），第一次激活便进入训练分布外。mask/age 同时有分布变化，但以下干预保留两者，仅改数值通道，已经足以消除本轮负预测。

验证集只有48个起点的4小时历史含此高值通道，测试有405个；验证总体MAE因而低估部署风险。验证含此高值的片段TCN MAE57.59，对照26.88；测试对应片段134.25，对照35.78 ppm。训练期未见特征不应仅依赖标准差下限处理。

## 已检查与剩余限制

- 原始快照、processed清单/数据、冻结权重和预测文件通过既有哈希核验。重建输入的标准化参数与checkpoint一致，重新推理与保存预测最大差为0 ppm，排除本轮重构引入的数值差异。
- 时间切分保证预测标签不跨集合；标准化只用训练时间段；标签取真实观测，不前向填充。现有检查未发现上述环节造成未来信息泄漏，但不能证明未知接收延迟不存在。
- TCN为直接多步输出，没有递归喂回；本轮失控不是递归误差累积。输出头线性无界，持续值残差初始化不能保证训练后的物理合理性。
- 最优验证MAE9.29优于持续值10.67，但验证RMSE27.57劣于15.74，且已有15个负预测。平均MAE不足以作为模型接纳条件。
- 单次时间留出使稀有新特征集中在后期；没有滚动验证。训练损失是标准化MAE，早停是ppm MAE，两者权重不同，但五个CO₂尺度39.67–45.77接近，不是1000倍输入放大的主解释。
- 目前无BA、真实人数与动作输入；这些信息限制可能影响变化段预测，但本轮不能量化其贡献，也不能以此替代已证实的输入问题。

## 下一步顺序（本次未训练）

1. 在训练/验证期先规定无观测、常数、二值和连续特征的编码契约。训练完全缺测通道应显式禁用并记录，不能让未来突然激活；二值事件无需按极小方差放大。缺测mask/age策略同时审阅。
2. 加输入支持域诊断和输出物理有效性接纳条件，不能只看总体MAE。评估负值、尾部、分点位及变化段；预测裁零不能代替根因修复。
3. 保留9500原始记录，建立可追溯质量标记，核实设备状态、人工干扰和原始上报；在训练/验证确定规则前，不按测试误差删点或选阈值。
4. 预先固定训练/验证时段滚动验证方案，再比较输入修复、TCN、持续值及后续LSTM。旧测试仅作已暴露压力案例；未来新增时间段才可用于新的独立最终测试。
