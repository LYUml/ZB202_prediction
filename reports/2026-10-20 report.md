# ZB202 房间 CO₂ 预测与通风情景模拟阶段汇报

**汇报日期：2026-10-20｜范围：当前工作区已实现工作｜时间统一为 UTC+8，另有说明除外。**

## 1. 工作目标与当前结论

本项目面向 ZB202 房间，利用真实 IoT 历史记录预测未来 CO₂ 浓度，并搭建通风情景模拟器，为后续新风策略研究提供基础。

目前形成两条相互独立的工作线：

1. **真实数据预测**：读取过去 4 小时的数据，预测未来 1 小时、5 个传感器点位的 CO₂。已完成数据整理、输入修复、多方法比较、特征消融、模型组合，以及冻结后的新增时段确认。
2. **物理情景模拟**：在明确假设下，比较不同风阀策略对 CO₂ 和累计新风体积的影响。已完成单房间 CO₂/AHU 模型与参数敏感性分析，尚未用真实设备响应标定。

当前保留的预测方案为：**精简 CO₂ 联合 TCN，三个固定随机种子的预测取算术平均。** 新增约四天真实数据上，MAE 为 **6.566 ppm**，持续值对照为 **8.321 ppm**，误差相对降低 **21.1%**，绝对减少约 **1.76 ppm**。

这一结果支持当前历史运行条件下的短期预测，但不能证明模型能可靠捕捉所有短时突变，也不能直接用于推导真实风阀最优开度。

五个 CO₂ 目标点位为 `AM103_05`、`AM103_06`、`AM103_07`、`AM103_08`、`AM308_01`。AM103 中位上报间隔约 5 分钟，AM308 约 10 分钟，因此 AM308 在五分钟标签网格上有更多真实缺测。

### 2.2 真实预测的输入与输出

| 项目 | 当前选中方案 |
| --- | --- |
| 时间分辨率 | 5 分钟 |
| 输入历史 | 过去 4 小时，即 48 个时间步 |
| 输入内容 | 五点 CO₂ 数值、五点可用标记、五点数据年龄、4 个时间周期编码 |
| 输入尺寸 | `48 × 19`；时间编码为日/周周期的正弦、余弦 |
| 输出内容 | 五个点位未来每隔 5 分钟的 CO₂，单位 ppm |
| 输出尺寸 | `12 × 5`，即每个预测起点输出 60 个数值 |
| 推理所需信息 | 仅预测起点及之前的历史，不需要未来真实标签 |

例如在 14:00 预测：输入此前 4 小时历史，输出 14:05、14:10……15:00 的五点浓度。

预测值输出为 JSON；实验产物另外保存模型权重、预测、实际观测、标签掩码和运行记录。绘图读取这些冻结产物，不重新训练。

### 2.3 通风模拟的输入与输出

**输入**：房间体积、室外 CO₂、人数日程、人均排放、送风量、新风比例曲线、执行器延迟，以及风阀策略。

**输出**：模拟 CO₂ 时间序列、风阀指令与位置、新风量、累计新风体积、策略摘要和参数来源记录。数据写入 `data/synthetic/`，与真实历史和预测结果分开保存。

目前预测模型未使用真实风阀动作历史，模拟器也没有被当作预测模型的真实训练标签来源。

## 4. 方法与评估设计

### 4.1 各方法的作用

| 方法 | 核心思路 | 设置与说明 |
| --- | --- | --- |
| 持续值预测 | 所有未来时刻均等于预测起点的当前值 | 不训练；用于检验模型是否优于简单惯性预测 |
| Ridge 回归 | 用带正则化的线性关系预测未来变化 | 历史压缩为末值、窗口均值和末首差；逐时距/点位拟合 |
| TCN | 用因果扩张卷积识别不同跨度的历史变化 | 联合读取五点；32 通道、卷积核 3、扩张率 1/2/4/8；直接输出未来变化 |
| LSTM | 用循环隐藏状态汇总历史 | 单层 32 隐藏单元；直接多步残差输出 |
| NLinear | 围绕当前值学习线性预测关系 | 仅读取五点数值，不包含缺测、年龄及日历通道 |
| DLinear | 将历史分解为趋势和残差后分别线性预测 | 输入信息与 NLinear 相同 |
| 缺测感知线性 | 在线性预测中保留缺测与年龄等信息 | 使用 19 通道输入 |
| 时间递推分解状态 RNN | 分解趋势与局部残差，沿时间递推 | 五点共享参数；受 PIAD-SRNN 启发的本地版本，不是原论文完整复现 |
| 正平衡值一阶松弛 | 让浓度随时间趋向一个预测的正平衡值 | 结构较强、变化形式受限；模型速率不等同实测换气率 |

TCN 采用“当前浓度 + 未来变化量”的输出方式，一次直接预测全部 12 个未来时距，避免逐步把自己的预测反复作为下一步输入。

**持续值为什么值得比较？** CO₂ 短期存在惯性，照抄当前值也可能很准。如果复杂模型不能稳定超过它，增加训练和维护成本的价值就不足。项目同时保留线性与其他神经网络对照，比较并不局限于持续值。

### 4.2 数据划分和公平比较

- 按时间先后划分，不随机打乱后划分训练和评估数据。
- 开发比较采用三个扩展时间窗口：训练/内部验证/外部开发终点分别为 `40%/45%/50%`、`50%/55%/60%`、`60%/65%/70%`。
- 标准化仅用训练段；内部验证用于早停，外部开发标签不进入梯度或早停选择。
- 每个样本的全部未来标签位于相应集合内；评估可以引用此前已发生的历史上下文。
- 神经模型使用固定种子 42、43、44，不挑选最佳种子。
- 方法在相同预测起点和相同有效真实标签上评分；缺失真实标签不计入误差。
- 原已暴露测试只作压力检查；新增确认段先冻结方案后评价，现已暴露，后续修改需要另取新时段。

TCN/LSTM 初筛上限 12 轮、早停耐心值 3；线性和结构候选上限 24 轮。两次触及 TCN 上限的拟合另作延长检查，最佳权重和预测没有改变。

这些是有限预算下的工程比较。候选的输入表示、参数量及正则化并非完全相同，不能据此断言某类架构在所有任务上更优。

## 5. 不同方法对比结果

### 5.1 开发阶段的最终比较

下表来自同三折开发窗口；神经候选先对固定三种子的**预测取平均**，再对三个开发窗口的指标等权平均。Ridge 与持续值为确定性对照。MAE、RMSE 越低越好，单位均为 ppm。

| 方法 | 开发 MAE | 开发 RMSE | 每个模型参数量 | 当前判断 |
| --- | ---: | ---: | ---: | --- |
| 持续值 | 9.514 | — | 无训练参数 | 基础对照 |
| Ridge | 8.247 | — | 按时距/点位拟合 | 简单且有竞争力的对照 |
| **TCN 三种子平均** | **7.435** | **10.479** | 26,204 | 当前保留方案 |
| LSTM 三种子平均 | 8.124 | 11.308 | 8,764 | 本轮未优于 TCN |
| NLinear 三种子平均 | 8.167 | 11.646 | 588 | 模型很小，但误差更高 |
| DLinear 三种子平均 | 7.953 | 11.394 | 1,176 | 优于 NLinear，未优于 TCN |
| 缺测感知线性三种子平均 | 8.021 | 11.176 | 54,780 | 本轮未优于 TCN |
| 时间递推分解状态 RNN 三种子平均 | 7.735 | 10.884 | 1,192 | 精度接近、参数更少的备选 |
| 正平衡值一阶松弛三种子平均 | 9.022 | 12.354 | 14,778 | 当前约束对复杂变化适应不足 |

注：`—` 表示本汇总未列出该项，不代表为零。NLinear/DLinear 不含额外的缺测、年龄及日历信息；Ridge 使用历史压缩表示，不能视为输入表示完全等价的比较。

### 5.2 完整特征是否更好？

以下为初筛阶段**单模型指标先按种子取平均，再按折等权平均**的 MAE，不同于上表“先平均预测”的组合口径。

| 方法 | 完整特征 MAE | 精简 CO₂/mask/age/日历 MAE |
| --- | ---: | ---: |
| Ridge | 8.885 | 8.247 |
| TCN | 8.455 | **7.547** |
| LSTM | 8.748 | 8.314 |

在本轮数据和预算下，精简输入整体更好。进一步用 seed42 做辅助特征与点位拆分筛选：

| TCN 输入/结构方案 | 三折外部开发 MAE |
| --- | ---: |
| 五点联合、仅 CO₂/mask/age/日历 | **7.462** |
| 加温湿度组 | 8.198 |
| 加占用组 | 8.115 |
| 加门磁组 | 8.020 |
| 加功率组 | 8.341 |
| 五个点位分别建独立 TCN | 7.678 |

以上候选均未通过预先规定的内部验证改善条件，因此没有继续追加种子。结果不说明辅助传感器永远无用，也不能把独立点位试验差异全部归因于跨点信息，因为其容量和参数共享方式也发生了变化。

| 方案 | 开发 MAE |
| --- | ---: |
| 三种子单模型 MAE 的均值 | 7.547 |

## 6. 冻结后的新增真实时段确认

先冻结三个 TCN 权重、输入规则和平均方式，再导出新增快照。使用旧导出截点之后的完整未来标签评价，没有重新训练、挑种子或调整混合权重。

- 预测起点：2026-10-16 17:25 至 2026-10-20 16:20（UTC+8）。
- 1,140 个重叠预测窗口，61,370 个有效真实标签项。
- 新段真实浓度约 280–721 ppm；没有包含旧时段 9500 ppm 尖峰。

| 指标 | TCN 三模型平均 | 持续值 |
| --- | ---: | ---: |
| 总体 MAE | **6.566** | 8.321 |
| 总体 RMSE | **8.634** | 11.229 |
| 提前 60 分钟 MAE | **7.027** | 8.730 |
| 60 分钟真实变化超过 20 ppm 的子集 MAE | **14.069** | 27.283 |
| 绝对误差第 99 百分位 | **24.630** | 32.000 |
| AM308_01 总体 MAE | 1.926 | **1.744** |
| 负浓度预测数 | 0 | 0 |

**结果解读：** 总体误差相对减少 21.1%，但平均绝对改善只有约 1.76 ppm，实际价值仍需结合通风决策需求评估。AM308 不如持续值，说明总体改善不等于所有点位改善。变化较大子集的平均误差有所改善，也不代表已可靠预测所有尖峰。

窗口重叠，同一真实标签可以在多个预测时距中重复使用，61,370 项不能当作独立样本量，也没有据此给出显著性或置信区间结论。开发分数和新增确认分数来自不同时段，不能用二者的差直接宣称模型又提升了一次。

## 7. 主要假设与适用范围

### 7.1 真实预测的数据假设

| 假设或规则 | 含义与限制 |
| --- | --- |
| 根据记录时间判断历史可用性 | 实际接收延迟未知，尚不能证明真实在线数据到达时序完全一致 |
| 五分钟对齐 | 不同传感器并非严格同时采样 |
| 历史数值最多保留 15 分钟、窗口覆盖至少 80% | 用于拒绝过期或缺测严重输入；阈值是建模选择，尚未经设备可靠性标定 |
| 占用是事件信号 | 不能直接当作真实人数，也不把最后事件视为确定的持续房间状态 |
| 五点分别预测 | 原始点位偏差和空间梯度尚未校准；不人为平移真实标签降低误差 |
| 历史运行条件具有一定延续性 | 没有真实 BA 动作历史，不能保证改变风阀策略后仍保持相同预测表现 |

### 7.2 物理模拟的参数假设

| 参数/机制 | 当前演示设置 | 状态 |
| --- | --- | --- |
| 房间有效体积 | 300 m³ | 假设，尚未由 IFC 核验 |
| 房间分配总送风量 | 0.5 m³/s | 假设，真实分配未知 |
| 室外 CO₂ | 420 ppm | 假设，非同步室外实测 |
| 人均 CO₂ 排放 | 5×10⁻⁶ m³/s/人 | 假设活动水平 |
| 渗透换气 | 0.2 次/小时 | 假设 |
| 风阀响应时间常数 | 120 秒 | 假设，未做设备响应辨识 |
| 室外空气比例端点 | 0.02～0.6 | 假设 |
| 风阀曲线 | 开度的 1.5 次幂映射 | 单调演示关系，非实测压差—流量模型 |
| 空间状态 | 单区充分混合 | 潜在区间平均状态，不直接等于任一原始传感器读数 |
| 风阀试验范围 | 20%～40% | 用户授权的模拟范围，非实测设备极限 |
| 风机控制 | 固定 60% | 根据当前 BA 基准设置；不据此推导频率线性关系 |
| 示例 CO₂ 目标 | 800 ppm | 仅用于模拟评价，不作为法规阈值或已确认推荐值 |

AHU 截图的 **8.168 m³/s 是总送风量，不是房间新风量**。房间分配和室外空气比例未测量，不能直接把总送风乘以开度作为房间新风量。截图中的风阀指令 30%、位置反馈 11% 分别保存，差异原因未知。

物理模型遵循 CO₂ 质量守恒：人的排放增加浓度，新风及渗透与室外交换空气。执行器用一阶响应模拟，浓度在固定流量子步内按解析解更新。仅凭 CO₂ 难以同时唯一辨识体积、人数/排放和风量，需要独立测量约束。

## 8. 通风策略模拟与敏感性结果

比较固定 20%、30%、40% 和 20%～40% 范围内 CO₂ 比例反馈。默认模拟 180 分钟，以假设人数日程推进；比例反馈在 CO₂ 升高后增大开度，目前不是 MPC。

针对房间分配送风量、体积、人均排放、执行器响应和开度曲线，构造 **144 组假设 × 4 种策略，共 576 个策略情景**。其中把全部 AHU 总风量分配给房间，仅作为极端压力情景，不当作真实分配。

| 策略 | 至少有一个分钟末超过示例 800 ppm 的情景数/144 | 最坏模拟峰值（ppm） |
| --- | ---: | ---: |
| 固定 20% | 76 | 2031.7 |
| 固定 30% | 62 | 1835.1 |
| 固定 40% | 43 | 1615.3 |
| 当前比例反馈 | 76 | 1647.1 |

这些计数是人为假设网格内的结果，**不是实际失败概率**。开度更大带来更低 CO₂ 的趋势依赖所设流量曲线；累计新风体积也不能直接解释为真实能耗或节能率。没有温湿度、盘管或冷冻水系统动态，也没有真实设备写入。

来源：最终技术报告中的通风敏感性结果（见本汇报相应章节）。

### 9.1 各点位误差

![各点位误差对比](../visualizations/co2_20261020/figures/fig_sensor_error.png)

前四个点位的 MAE 低于持续值，AM308 略差。各点位浓度分布和标签密度不同，不能仅按绝对误差大小判断传感器质量。

### 9.2 预测与实测的局部对比

![30分钟预测与实测及偏差](../visualizations/co2_20261020/figures/fig_prediction_overlay.png)

展示 2026-10-18、AM103_05 的提前 30 分钟预测。固定选择中间完整日、第一个点位和午间三小时，不按模型误差挑选时段，未平滑实测数据。上图看浓度，下图看预测减实测，越靠近零线越好。

**局部图揭示的问题：** TCN 输出较保守，对实测的快速升降跟随不足。平均误差较低可能部分来自减少无把握的短时波动预测；现有证据不能区分这些起伏究竟来自真实环境变化、测量噪声或其他因素。因此不能把“总体 MAE 更好”等同于“尖峰预警能力已满足要求”。

### 9.3 预测时距与误差

![预测时距与MAE](../visualizations/co2_20261020/figures/fig_horizon_error.png)

确认期内整体上预测越远误差越大。TCN 总体优于持续值，但是否满足实际通风决策容差，需要进一步定义需求。

浓度预测没有天然的分类“准确率”。本阶段以 MAE、RMSE 为主；CSV 中误差不超过 10 ppm 的比例仅是描述统计，10 ppm 不是设备精度或已确认合格标准。

## 10. 当前不足与下一步

| 当前不足 | 下一步建议 |
| --- | --- |
| 确认期仅约四天、浓度范围有限 | 固定现有方案，积累更长未参与开发的新时段，覆盖不同占用和运行条件 |
| 对局部短时波动跟踪不足 | 单独评价上升段、峰值低估、提前预警时间、漏报与误报；先明确任务容差和阈值 |
| 点位差异与 AM308 退化未解释 | 核查位置、采样机制、时间同步及校准，避免直接修改真实标签 |
| 缺少真实 BA 动作历史 | 获取风阀指令/反馈、总送风/新风量及风机状态的同步记录 |
| 房间体积和风量分配未知 | 补空间核验及独立流量测量，为物理模型辨识提供约束 |
| 模拟不能直接支撑真实控制 | 标定后再研究多情景 MPC、舒适性和能耗；当前不输出真实最优开度结论 |

当前阶段完成了可追溯的预测基线、有限预算下的方法筛选和明确标注假设的通风模拟。下一阶段应优先补数据与任务定义，而不是只在已反复使用的开发集上继续增加模型复杂度。
