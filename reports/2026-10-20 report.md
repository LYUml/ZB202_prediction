# ZB202 CO₂ 预测阶段汇报

**日期：2026-10-20**

本阶段完成了：**利用过去 4 小时的传感器记录，预测未来 1 小时的 CO₂，并比较不同预测方法。**

## 1. 输入和输出

| | 内容 |
| --- | --- |
| 数据来源 | ZB202 房间的真实 IoT 历史记录 |
| 输入 | 过去 **4 小时**、**5 个点位**的 CO₂，加上数据缺失标记、数据年龄及时间信息 |
| 时间间隔 | **5 分钟** |
| 输出 | 未来 **1 小时**，每隔 5 分钟的五点 CO₂ 浓度，共 **12 × 5 个预测值**，单位 ppm |

当前采用 **TCN 时间卷积网络**：从历史变化中学习规律，一次预测未来全部时刻。分别训练三个固定随机种子的模型，再将预测取平均。

## 2. 方法对比

所有方法都预测相同的五点 CO₂，采用三个时间窗口进行开发比较。**MAE 是预测与实测平均相差多少 ppm，越低越好。**

| 方法 | 简单理解 | 开发 MAE（ppm） |
| --- | --- | ---: |
| 持续值 | 猜未来一直等于现在 | 9.51 |
| Ridge | 简单线性回归 | 8.25 |
| LSTM | 用循环网络记住历史 | 8.12 |
| NLinear | 根据当前值学习线性变化 | 8.17 |
| DLinear | 拆分趋势后做线性预测 | 7.95 |
| 缺测感知线性 | 在线性模型中加入缺测等信息 | 8.02 |
| 分解状态 RNN | 拆分趋势和波动，沿时间递推 | 7.74 |
| 一阶松弛模型 | 预测浓度逐渐趋向某个平衡值 | 9.02 |
| **TCN 三模型平均** | **用卷积识别历史变化，再综合三个模型** | **7.44** |

**当前保留 TCN 三模型平均。** 加入温湿度、占用、门磁或功率，以及延长训练、混合 Ridge，在本轮试验中都没有进一步改善。

对比采用相同预测起点和真实标签，但部分方法的输入表示、参数量和训练预算不同；结果仅代表本项目当前试验，不代表某类模型普遍更好。

## 3. 新增真实数据上的结果

选定并冻结 TCN 后，使用新增约 **4 天**的数据检查，没有重新训练或根据这段数据调参。

| 指标 | TCN 三模型平均 | 持续值 |
| --- | ---: | ---: |
| **总体 MAE（ppm）** | **6.57** | 8.32 |
| 提前 60 分钟 MAE（ppm） | **7.03** | 8.73 |

**总体平均误差减少约 21%，实际少差约 1.76 ppm。** 这里的 21% 是误差降幅，不是“准确率”。开发比较与新增确认是不同时间段，分数不能直接当作同一场考试比较。

## 4. 当前能说明什么？

**已经做到：** 建立真实数据预测流程，完成多方法比较，TCN 在当前新增确认期总体优于简单预测。

**还不能说明：** 四天数据没有覆盖极端高浓度，尚不足以证明长期表现；模型也没有学习经过验证的风阀动作响应，不能直接推荐真实最优开度。

另外已搭建通风模拟器，比较固定 20%/30%/40% 风阀和 CO₂ 反馈策略。房间体积、分配风量等仍是假设，模拟结果不能作为真实通风或节能效果。

**下一步重点：** 获取更长的新数据，重点检查浓度上升和尖峰；补齐传感器校准、真实风量和风阀动作记录。
